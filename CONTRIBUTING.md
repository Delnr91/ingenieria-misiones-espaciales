# Contribuir

Gracias por ayudar a mejorar esta biblioteca. Una contribución útil describe el problema, propone una mejora y aporta fuentes verificables.

- Señala si el texto procede de una fuente, es una explicación propia o una hipótesis.
- Respeta derechos, datos privados y licencias; no subas obras completas protegidas sin autorización.
- Utiliza ejemplos sintéticos y unidades explícitas.
- Identifica qué se comprobó y qué queda pendiente.
- Los análisis didácticos no deben presentarse como certificación de seguridad o aptitud para vuelo.
- Una corrección puede proponerse mediante una incidencia o una solicitud de cambios en GitHub.

El proyecto es independiente y no representa a NASA, los autores del libro ni a sus editoriales.
