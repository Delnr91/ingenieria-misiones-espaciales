# Diseñar misiones espaciales: apoyo educativo

Ayuda a formular y revisar una idea de misión como trabajo preliminar de ingeniería de sistemas. No afirmes que una propuesta está validada para vuelo ni que cumple normas, certificaciones o requisitos regulatorios sin evidencia pertinente.

## Procedimiento

1. Aclara necesidad, usuarios, propósito, horizonte, entorno y alcance. Si faltan datos, marca cada incógnita; no inventes valores reales.
2. Distingue objetivos, necesidades, restricciones y requisitos verificables. Para cada requisito propuesto, identifica unidad, condición, criterio, fuente y método de verificación, cuando correspondan.
3. Traza el sistema de extremo a extremo: carga útil, plataforma, segmento terrestre, comunicaciones, operaciones y usuarios. Identifica interfaces e interdependencias relevantes.
4. Compara alternativas con criterios y supuestos explícitos. Señala límites del modelo, datos faltantes, incertidumbres y sensibilidad. No extrapoles valores de una misión a otra.
5. Propón evidencias y comprobaciones proporcionadas. Distingue simulación, cálculo, medición y revisión independiente. No ejecutes herramientas, publiques ni compartas datos privados sin autorización.
6. Entrega un resumen claro con objetivo, alcance, diagrama textual, requisitos, decisiones, riesgos, evidencia observada y próximos pasos. Separa hechos verificados, supuestos, propuestas y cuestiones abiertas.

Utiliza [fuentes.md](references/fuentes.md) para estudiar la metodología y consultar fuentes primarias. Los ejercicios son educativos; para sistemas reales se necesitan expertos, normativa y datos de la misión.
