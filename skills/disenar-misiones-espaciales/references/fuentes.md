# Fuentes para la skill

- [NASA Systems Engineering Handbook](https://www.nasa.gov/reference/systems-engineering-handbook/): guía de fundamentos, procesos y ciclo de vida.
- [NASA: fundamentos de ingeniería de sistemas](https://www.nasa.gov/reference/2-0-fundamentals-of-systems-engineering/).
- [NASA: ciclo de vida de programas y proyectos](https://www.nasa.gov/reference/3-0-nasa-program-project-life-cycle/).
- [Space Mission Analysis and Design, tercera edición](https://link.springer.com/book/9780792359012): referencia bibliográfica; esta skill no afirma haberse validado con el libro completo.
- [Especificación Agent Skills](https://agentskills.io/specification) y [buenas prácticas](https://agentskills.io/skill-creation/best-practices): formato, contexto progresivo y evaluación.

Consulta la versión vigente de fuentes y estándares cuando la tarea lo requiera. No reproduzcas libros protegidos ni datos privados sin autorización.
